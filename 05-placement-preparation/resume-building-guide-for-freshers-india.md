# Resume Building Guide for Freshers in India: Structure, Projects and Examples

**An educational resource by Career Captain Global Solutions**

A fresher resume should help a recruiter quickly understand your education, relevant skills, projects and experience. It should be accurate, readable and tailored to the role. A resume cannot compensate for missing skills, but it can make relevant evidence easier to evaluate.

## 1. Recommended structure

1. Name and professional contact details.
2. Short role-focused summary (optional; keep it specific).
3. Education, including degree, institution and expected/completion date.
4. Skills that you can explain or demonstrate.
5. Projects with your contribution and outcomes.
6. Internships, volunteering, part-time work or relevant experience.
7. Certifications or achievements relevant to the target role.
8. Portfolio, GitHub or professional profile links where useful.

Include personal information only when it is required and appropriate. Avoid unnecessary sensitive details.

## 2. Write useful project bullets

A strong bullet explains the task, your action, tools or method, and a verifiable result.

Weak: “Made a website using HTML.”

Stronger: “Built a responsive three-page event website using HTML and CSS; implemented navigation and tested layouts on desktop and mobile.”

Do not invent percentages, users, revenue, rankings or client impact. If you cannot quantify a result honestly, describe the deliverable and your contribution.

## 3. Tailor the resume

- Read the job description and identify essential requirements.
- Put the most relevant skills and projects where they are easy to find.
- Use the employer's terminology only when it accurately describes your experience.
- Remove unrelated detail that pushes important evidence off the first page.
- Keep formatting consistent and headings clear.
- Follow the employer's requested file type and naming convention.

## 4. Common mistakes

- Generic objective statements.
- Listing tools you cannot use.
- Copying job-description keywords without evidence.
- Long paragraphs instead of concise bullets.
- Spelling, date or contact errors.
- Decorative graphics that make the document hard to scan.
- Fake experience, certificates or project results.

## 5. Before submitting: checklist

- [ ] Contact details are correct.
- [ ] Education dates and marks are accurate.
- [ ] Skills are relevant and defensible.
- [ ] Project descriptions explain your own contribution.
- [ ] Links work and public repositories contain no secrets.
- [ ] The document is readable on a phone and desktop.
- [ ] File name is professional.
- [ ] Resume matches the role and application instructions.

## 6. Keep a master resume

Maintain a full record of projects, activities and skills. Create a tailored version for each role instead of sending the same document everywhere. Keep a simple application tracker with company, role, date, version and follow-up status.
