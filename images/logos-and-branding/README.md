# Logos and Branding — Visual Library

This folder stores approved brand assets for Career Captain Global Solutions and the Career Roadmaps India open-source project.

The objective is to maintain consistent, accurate brand representation across repository documents, educational resources, presentations and digital platforms.

## Official Brand Assets

The following assets may be stored here when supplied and approved by Career Captain Global Solutions.

| Asset | Recommended filename | Purpose |
|---|---|---|
| Official primary logo | `career-captain-logo.png` | Main brand identification |
| Transparent logo | `career-captain-logo-transparent.png` | Use on suitable backgrounds |
| Official monochrome logo | `career-captain-logo-monochrome.svg` | Approved single-colour applications |
| Brand icon | `career-captain-brand-icon.png` | Small visual applications |
| Brand guidelines | `career-captain-brand-guidelines.pdf` | Official usage instructions |

These are recommended filenames, not confirmation that the corresponding assets have been supplied.

## Mandatory Logo Guidelines

- Use only the original logo supplied or approved by Career Captain Global Solutions.
- Never redraw, recreate, reinterpret or substitute the logo.
- Do not alter its proportions, typography, colours or design.
- Do not stretch, distort or crop the logo.
- Use transparent versions where appropriate.
- Maintain sufficient clear space around the logo.
- Ensure adequate contrast against the background.
- Do not place the logo on visually unsuitable backgrounds.
- Do not create unofficial variations.

## Brand Usage

Approved assets may be used in:
- Career roadmaps and educational guides.
- Career skills infographics.
- Study-abroad visual resources.
- Educational presentations.
- Project documentation.
- Approved digital promotional materials.

Use should remain consistent with the official brand guidelines.

## File Management

- Store only approved brand assets.
- Use descriptive, lowercase filenames.
- Prefer SVG for approved scalable logos when available.
- Preserve the original source files.
- Do not overwrite official assets with modified versions.
- Record relevant ownership and usage information.
