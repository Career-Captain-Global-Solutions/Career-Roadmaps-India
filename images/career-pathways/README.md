# Career Pathways — Visual Library

This folder contains visual resources that help students understand educational choices, career pathways and professional opportunities.

## Planned Visual Resources

| No. | Visual asset | Purpose |
|---|---|---|
| 01 | Career options after Class 10 | Explain different streams and educational pathways |
| 02 | Career options after Class 12 MPC | Show engineering, science and alternative career options |
| 03 | Career options after Class 12 BPC | Explain healthcare, life sciences and related careers |
| 04 | Choosing the right career | Illustrate the career exploration and decision-making process |
| 05 | Career planning roadmap | Show the journey from education to employment |
| 06 | Career exploration framework | Help students explore interests, abilities and opportunities |

## Asset Guidelines

- Use clear, student-friendly visual explanations.
- Prefer diagrams and infographics over text-heavy images.
- Use consistent typography and visual styling.
- Use the original Career Captain logo only when the approved logo asset is available.
- Optimise files for web use.
- Verify image licensing before publication.

## Naming Convention

Use descriptive filenames, for example:

- `career-options-after-class-10.webp`
- `career-options-after-class-12-mpc.webp`
- `career-options-after-class-12-bpc.webp`
- `career-planning-roadmap.svg`
