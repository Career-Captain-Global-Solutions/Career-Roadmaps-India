## Asset Guidelines

- Prioritise technical accuracy and educational clarity.
- Use readable diagrams and properly labelled illustrations.
- Avoid misleading representations of engineering concepts.
- Maintain consistent Career Captain branding.
- Use the original approved Career Captain logo without recreating or modifying it.
- Optimise assets for web performance.
- Verify licensing and attribution requirements.
