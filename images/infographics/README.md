# Infographics — Visual Library

This folder contains educational infographics, comparison charts, process diagrams and visual explainers for the Career Roadmaps India project.

The objective is to simplify complex career and educational information through clear, accessible visual communication.

## Design Guidelines

- Use one clear central message per infographic.
- Present information in a logical visual sequence.
- Use readable typography and sufficient contrast.
- Avoid overcrowded layouts and unnecessary text.
- Use charts and diagrams only when they improve understanding.
- Ensure statistics and factual claims are supported by reliable sources.
- Design for desktop and mobile viewing.
- Maintain consistent Career Captain branding.
- Use the original approved Career Captain logo without recreating or modifying it.

## Recommended Formats

| Format | Recommended use |

## Quality and Attribution

Every infographic must:
- Be original or appropriately licensed.
- Use accurate and verifiable information.
- Include source attribution where required.
- Avoid misleading statistics or exaggerated claims.
- Be checked for spelling, readability and visual consistency.
