# Career Skills — Visual Library

This folder contains visual resources designed to explain essential life skills, employability skills and professional competencies.

The objective is to make career development concepts easier to understand through clear, engaging and practical visuals.

## Planned Visual Resources

| No. | Visual asset | Purpose |
|---|---|---|
| 01 | Communication skills infographic | Explain verbal, written and non-verbal communication |
| 02 | Teamwork and collaboration infographic | Illustrate effective teamwork and shared responsibilities |
| 03 | Critical thinking framework | Explain analytical thinking and problem-solving |
| 04 | Time management matrix | Visualise priorities, deadlines and productivity |
| 05 | Leadership skills infographic | Explain leadership behaviours and responsibilities |
| 06 | Emotional intelligence framework | Illustrate self-awareness, self-regulation and empathy |
| 07 | Adaptability and resilience infographic | Explain responding to change and learning from setbacks |
| 08 | Creativity and innovation framework | Show how ideas develop into practical solutions |
| 09 | Digital literacy and AI skills infographic | Explain essential digital and AI competencies |
| 10 | Professional etiquette and networking infographic | Illustrate workplace behaviour and professional relationships |

## Asset Guidelines

- Make visuals understandable without requiring lengthy explanations.
- Use accurate, practical and student-friendly examples.
- Prefer clear diagrams, frameworks and infographics.
- Avoid overcrowded layouts and excessive text.
- Maintain consistent typography and Career Captain branding.
- Use the original approved Career Captain logo without recreating or modifying it.
- Optimise images for web performance.
- Verify licensing and attribution requirements.
