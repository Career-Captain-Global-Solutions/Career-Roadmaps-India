# Images and Visual Resources

This directory contains visual assets used in the Career Roadmaps India open-source project by Career Captain Global Solutions.

Our objective is to create a consistent, accessible and visually engaging learning experience for students, graduates and young professionals.

## Visual Asset Categories

The following categories organise the visual library.

| Folder | Purpose |
|---|---|
| `career-pathways/` | Career pathways, stream selection and career exploration diagrams |
| `engineering/` | Engineering branches, specialisations and technical career diagrams |
| `study-abroad/` | Study destinations, application processes and international education infographics |
| `career-skills/` | Communication, leadership, teamwork and other professional skills |
| `infographics/` | Educational charts, comparison graphics and learning illustrations |
| `logos-and-branding/` | Approved Career Captain brand assets and logo files |

## Image Guidelines

- Use original or appropriately licensed images.
- Maintain consistent Career Captain branding.
- Use the original Career Captain logo without recreating or modifying it.
- Optimise images for web performance without unnecessarily reducing visual quality.
- Use descriptive, lowercase filenames with hyphens.
- Provide attribution wherever required by the image licence.
- Include alternative text when images are used in Markdown documents.
- Avoid duplicate, blurry, watermarked or misleading images.
- Do not upload confidential, copyrighted or unauthorised material.

## Recommended File Formats

| Format | Recommended use |
|---|---|
| WebP | Optimised photographs and illustrations |
| SVG | Logos, icons and scalable diagrams |
| PNG | Transparent graphics and diagrams |
| JPEG | Photographs where WebP is unsuitable |

## File Naming Convention

Use descriptive filenames.

Examples:

- `career-options-after-class-10.webp`
- `computer-science-career-pathway.svg`
- `study-in-germany-roadmap.webp`
- `leadership-skills-infographic.png`
- `communication-skills-diagram.svg`

## Image Attribution and Licensing

Every external visual asset must have a licence compatible with its intended use.

Where attribution is required, record:

- Asset filename.
- Original creator.
- Source or original URL.
- Licence name.
- Attribution details.

Do not assume that an image is free to use simply because it is available online.

## Adding New Visual Assets

1. Select the appropriate category.
2. Verify ownership or licensing permissions.
3. Optimise the image.
4. Use a descriptive filename.
5. Add attribution information where required.
6. Update the relevant guide with the image link.
7. Check that the image displays correctly on GitHub.
