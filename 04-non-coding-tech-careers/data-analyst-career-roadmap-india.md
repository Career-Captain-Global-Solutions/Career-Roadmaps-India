# Data Analyst Career Roadmap in India: Skills, Tools and Projects

**An educational resource by Career Captain Global Solutions**

Data analysts help organisations turn data into useful information for decisions. The work may involve collecting, cleaning, validating, analysing and presenting data. It requires more than creating charts: analysts must understand the question, assess data quality and explain limitations.

## 1. Typical responsibilities

- Clarify the business or research question.
- Identify relevant data sources and permissions.
- Clean, transform and validate datasets.
- Use spreadsheets, SQL or analytical tools.
- Analyse patterns and investigate anomalies.
- Build reports or dashboards.
- Explain findings to non-technical stakeholders.
- Document assumptions and limitations.

## 2. Core skills

**Quantitative foundations:** percentages, averages, distributions, variation, correlation and basic statistical reasoning.

**Data handling:** spreadsheets, data cleaning, joins, filtering and validation.

**Querying:** SQL is commonly useful for working with relational data.

**Visualisation:** select charts that communicate the question accurately.

**Communication:** explain findings, uncertainty and limitations clearly.

Python or R can be useful for some roles, but tool requirements depend on the job.

## 3. A sensible learning sequence

1. Spreadsheet formulas, sorting, filtering and pivot tables.
2. Descriptive statistics and data quality checks.
3. SQL: SELECT, WHERE, GROUP BY, JOIN and subqueries.
4. Data visualisation and dashboard design.
5. Introductory scripting for repeatable analysis where relevant.
6. Business context and concise reporting.

## 4. Portfolio projects

Use public, permitted datasets. For each project:
- State the question.
- Cite the dataset and its licence or terms.
- Explain cleaning decisions.
- Show the analysis method.
- Present a small set of meaningful charts.
- State findings without overstating causation.
- List limitations and possible next steps.

Example themes include public transport, weather, education, public health or retail data. Avoid publishing personal or confidential data.

## 5. Entry pathways

Possible starting roles include reporting analyst, data operations associate, MIS executive, junior data analyst or business intelligence support. Titles and prerequisites differ. Some positions expect strong statistics or programming; others focus on reporting and operations.

## 6. Interview preparation

Practise SQL queries, spreadsheet tasks, data interpretation and explaining an analysis. Be ready to identify data quality problems and explain why a chart or metric could mislead.

## 7. 10-week plan

Weeks 1–2: Spreadsheets and basic statistics.

Weeks 3–4: SQL fundamentals and practice datasets.

Weeks 5–6: Visualisation and dashboard design.

Weeks 7–8: Complete one end-to-end project.

Weeks 9–10: Document the portfolio, revise your CV and practise role-specific interviews.
